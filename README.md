# Why was it made?
A few weeks ago, I had posted my first ever font to r/fonts, Maple Sans. It quickly gained traction because the font looked like a troll post and I was mistaking advice worded like hate for hate comments. My atittude had ruined my reputation, as my last two fonts (MP Letter Gothic Propo and JuniSans) barely got any traction, despite the former being praised. I wanted to start fresh, and so I began developing Maple Sans Recast as a sort of "memorial" to Maple Sans. I had added many features, too, like oldstyle figures, tabular figures, slashed zero, and also 2 more weights: **Black** and **Extrabold**. I wanted this to be a good font for basic usage e,g, websites, body text, etc.

# How many versions are there?
Regular, Medium, Semibold, Bold, Extrabold and Black. I'll work on Light and the italic versions later.

# Can I contribute to the project?
Absolutely! You can add Cyrillic, Greek, IPA, Coptic, anything you want, even a variable version of the font.
