# Project files
This is for people who want to contribute to Maple Sans Recast.

_Recommended: Inkscape, FontForge_

# What's inside?
**Fontforge files:** The base font files for Maple Sans Recast. You can use it however you want as long as you credit me.
**Weights:** In case you want to make changes to other weights, it provides em unit sizes for Change Weight window (make sure to use CJK)
**SVG file:** An SVG that is super easy to modify.
